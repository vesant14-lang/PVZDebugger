# Security Policy

## Supported versions

Security fixes are considered for the latest official PvZ Debugger release.
Older releases may not receive updates; upgrade to the newest release before
reporting an issue when possible.

## Reporting a vulnerability

Do not report security-sensitive issues in a public GitHub issue. Use GitHub's
private vulnerability reporting feature or contact the repository maintainer
privately through the contact method listed on the repository profile.

Please include:

- The PvZ Debugger release version.
- Windows version and architecture.
- The affected feature or action.
- Reproduction steps that do not require sharing game files.
- A log excerpt with personal paths and sensitive information removed.

Allow reasonable time for investigation before publishing details. Do not
include Plants vs. Zombies executables, ROMs, SWFs, save files, proprietary
assets, memory dumps, or copied game resources in a report.

## Scope

This policy covers the PvZ Debugger application, its official distribution
files, and the repository's release infrastructure. It does not cover
Plants vs. Zombies, PopCap Games, Electronic Arts, Flashpoint, Ruffle, game
emulators, third-party repacks, or unofficial modifications.

PvZ Debugger is an offline research and modification tool. It is not intended
to bypass online services, alter third-party systems, or distribute game
content.

## Disclosure

Reports will be reviewed in good faith. If a report is confirmed, the issue
may be fixed in a future release and credited if the reporter requests it.
